# 评测校验与过时测试修复 — 2026-11-06

用户明确允许修复迁移前就存在的不合理代码。本次是独立于目录迁移的行为修复。

## 代码修复
- response_errors 对非法 group_id 类型和过大数值返回错误，不再抛类型或溢出异常。
- 证据组按支持选项去重；多个组重复支持同一选项不能构成有效 Conflict。
- ANSWERABLE 必须且只能支持所选选项；INSUFFICIENT 不能同时声明有支持选项。这与现有 v2.2 的集合 S 决策规则一致。
- 空的 Option 前缀描述被拒绝。
- Conflict 的 label_correct 只有在标签正确且响应校验通过时才为真；decision_matches_gold 单独保留原始标签匹配诊断。无效结果仍保留在分母和输出中。
- merge_full 的 complete 状态包含格式有效性；有 invalid_records 时返回非零退出码，而不是误报完成。
- 新结果和验证报告记录 response_validation_version=v2.2-validator-20261106。加载历史冻结 prompt 时兼容缺少该字段，标记 legacy-unversioned。
